🧠 À retenir : une classe grammaticale est la catégorie d'un mot. Dans le quiz, tu dois trouver la classe puis, quand elle existe, le sous-type.

🟦 Les déterminants

Ils accompagnent généralement un nom.

article défini : le, la, les, l' article indéfini : un, une, des possessif : mon, ma, mes... démonstratif : ce, cet, cette, ces indéfini : chaque, plusieurs, quelques... numéral : deux, trois, quatre...

Exemple : Les petits chiens → « Les » = déterminant, article défini.

🟩 Les noms

Ils servent notamment à désigner une personne, un animal, une chose, un lieu ou une idée.

nom commun nom propre

Exemples : chat = nom commun ; Marie = nom propre.

🟨 Les adjectifs

L'adjectif qualificatif donne une information sur un nom.

adjectif qualificatif

Exemple : un chien rapide → « rapide » = adjectif qualificatif.

🟪 Les pronoms

Ils peuvent remplacer un nom ou un groupe nominal.

personnel : je, tu, il, nous... possessif démonstratif : celui, celle... relatif : qui, que, dont, où... indéfini : quelqu'un, personne, chacun...

Exemple : Il court. → « Il » = pronom personnel.

🟥 Les verbes

Ils expriment généralement une action ou un état et peuvent être conjugués.

verbe

Exemple : Le garçon court → « court » = verbe.

🟧 Les adverbes

Ils apportent une précision, par exemple sur un verbe, un adjectif ou un autre adverbe.

adverbe

Exemple : Il court rapidement → « rapidement » = adverbe.

⬛ Les prépositions

Elles introduisent notamment un complément.

àdanssur sousavecsans pourparchez versentre devantderrière

Exemple : Il va dans la maison. → « dans » = préposition.

🔵 Les conjonctions

Elles servent notamment à relier des mots, groupes de mots ou propositions.

coordination : mais, ou, et, donc, or, ni, car subordination : quand, lorsque, parce que, si...

Exemples : « et » = conjonction de coordination ; « quand » = conjonction de subordination.

💬 Les interjections

Elles expriment une émotion, une réaction ou une exclamation.

Oh !Ah !Zut !Hélas !Bravo !

Exemple : Oh ! Quelle surprise ! → « Oh » = interjection.
